# Assets: sources and licenses

## Provided asset pack (`assets/`)

Everything in `assets/` comes unchanged from the challenge repository [junglegaming/game-developer-challenge](https://github.com/junglegaming/game-developer-challenge) (`assets/`), and is used under the terms that repository grants for this challenge:

| Group | Files | Notes |
| --- | --- | --- |
| Ships, ship parts, effects | `png/*/ships`, `png/*/ship_parts`, `png/*/effects`, `spritesheet/ships_miscellaneous_sheet.*`, `vector/ships_miscellaneous_vector.*` | The sprites match Kenney's *Pirate Pack* ([kenney.nl](https://kenney.nl/assets/pirate-pack), CC0 1.0 public domain) |
| Tiles | `png/*/tiles`, `tilesheet/*`, `vector/tiles_vector.*` | Same origin (Kenney *Pirate Pack*, CC0 1.0); 64 px / 128 px (retina) grid |
| UI (menus, HUD, controls) | `png/*/ui`, `spritesheet/ui_sheet*.json/png` | Pirate Battle UI asset pack, provided with the challenge |
| Sounds | `sounds/*.wav` | Provided with the challenge |
| Reference images | `sample*.png`, `preview.png`, `ui_scene_background.png`, `logo_jungle_gaming.svg` | Provided with the challenge. `ui_scene_background.png` is used as the menu backdrop |

## Derived files (generated, not committed)

`scripts/prepare-assets.mjs` builds `public/game/` from `assets/` before every `dev` and `build`:

- converts the Starling/Sparrow XML ship atlas into PixiJS spritesheet JSON (no pixels change)
- generates spritesheet JSON for the 16 × 6 tile grid at 1× and 2×. Frame `tile_N` is grid cell `N−1` in row-major order, which was checked pixel by pixel against the individual `tile_N.png` files
- copies the UI atlases, the retina UI PNGs used by the DOM menus and the menu backdrop
- packs the WAV sounds, byte for byte, as base64 into two JSON bundles (`sounds/effects.json` and `sounds/ambience.json`). Download managers such as IDM intercept requests for `.wav` files and take them away from the page; they never intercept JSON. Over the wire (brotli) the bundles are smaller than the original WAV files

## Created for this project

- **Procedural textures:** the water ring, projectile trail and smoke puff are drawn at runtime on a 2D canvas (`src/game/render/proceduralTextures.ts`). No external files.
- **Fonts:** system fonts only (`Trebuchet MS` / `Arial Black` stacks). No third-party font files are shipped.
- **Mock data:** fixture captains and scores in the mock API are generated by `src/mocks/fixtures.ts`.
